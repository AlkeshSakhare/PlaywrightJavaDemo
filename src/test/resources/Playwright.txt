Playwright
-----------
Run below command in java project to open codegen
mvn exec:java -e -D exec.mainClass=com.microsoft.playwright.CLI -D exec.args="codegen amazon.in"

playwright.$("locator") -> get single locator
playwright.$$("locators") -> get list of locators
playwright.inspect("locator") -> show locator in element tab
